# 100 Days of Azure Cloud Engineering

A hands-on learning journey to build practical skills in Microsoft Azure, Linux, networking, security, and cloud operations.

## About this repository

I am working through 100 days of Azure cloud engineering labs on KodeKloud. For each lab, I document the task, the commands I used, why those commands matter, verification evidence, problems encountered, and the connection to real infrastructure work.

The objective is to develop repeatable engineering habits, not just complete exercises.

## Security and disclosure

Lab credentials, access tokens, and private SSH keys are never committed. Screenshots are manually reviewed and redacted before publication. Resource group names and tenant identifiers in this repository are generalized when they do not add educational value.

## Note

These are learning labs, not production deployments. Documentation distinguishes between commands actually executed and planned steps. Some Azure resources exist only during short-lived training sessions.
